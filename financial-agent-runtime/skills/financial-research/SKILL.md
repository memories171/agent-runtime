# 金融研究与财报分析

1. 先确认研究对象、报告期间、币种、会计口径、合并范围和比较基准。
2. 只通过已授权数据源获取财务报表、公告、行情和研究资料；记录来源、时间戳和数据版本。
3. 对收入、利润、现金流、负债、资本开支和关键比率进行勾稽检查；注明重述、缺失值和口径差异。
4. 将事实、计算结果、假设和观点分开；每个重要数字必须能追溯到来源。
5. 对市场数据注明报价时间、交易时区、币种和是否延迟。
6. 不生成保证收益或确定性预测，不代表客户给出个性化买卖建议，不执行交易。
7. 对重大不确定性、数据冲突和潜在利益冲突明确升级给研究员或合规人员。
