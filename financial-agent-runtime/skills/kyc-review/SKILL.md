# KYC 资料完整性辅助审查

1. 按机构当前有效的 KYC 清单检查资料是否齐全、是否过期、是否存在字段冲突。
2. 逐项列明证据来源、文件日期、缺失字段和待客户补充事项。
3. 对同名、地址差异或身份信息不一致仅标记为待核实，不推断欺诈。
4. 不自行批准或拒绝客户，不更改客户风险等级，不将缺失资料直接推断为不合规。
5. 涉及 PEP、制裁或负面新闻命中时，仅整理来源和匹配差异，交由合规人员核验身份与适用政策。
6. 输出结构化审查清单、证据引用和升级理由；最终结论由授权审核人作出。
