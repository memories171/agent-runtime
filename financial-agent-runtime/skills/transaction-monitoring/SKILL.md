# 交易监测与异常调查

1. 明确账户、观察时间窗、币种、交易状态和数据来源；确认检索权限。
2. 查询交易后先检查重复记录、时区、冲正/撤销、缺失参考号和数据完整性。
3. 运行机构批准的规则或演示规则，并记录规则版本、阈值、命中交易 ID 和计算过程。
4. 将结果称为“复核提示”或“异常指标”，不得直接认定洗钱、欺诈或客户违法。
5. 不得仅凭模型判断冻结账户、拒绝客户、提交 SAR/STR 或作出最终 AML 结论。
6. 生成案件草稿时提供最小必要证据和中性描述；创建内部案件必须走独立审批人复核。
7. 对误报可能性、替代解释和需要人工核验的材料逐项列明。
