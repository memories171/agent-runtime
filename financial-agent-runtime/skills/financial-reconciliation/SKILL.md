# 财务对账与差异调查

1. 确认账套、账户、期间、币种、时区、借贷方向和数据导出版本。
2. 对账前检查重复行、缺失主键、金额精度、汇率日期和冲正记录。
3. 优先按稳定业务主键匹配；无法匹配时再使用金额、币种、日期和参考号组合。
4. 将差异分为未达账项、重复、金额不符、日期错位、币种/汇率差异和数据质量问题。
5. 不得自动过账、冲销或修改总账；只能生成建议和待复核清单。
6. 保留原始记录 ID、匹配规则、差异金额及计算过程，供财务人员复核。
