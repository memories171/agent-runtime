# 信用风险辅助分析

1. 明确借款主体、授信产品、财务期间、合并口径和数据日期。
2. 只使用授权财务报表、还款记录、担保信息和机构批准的数据源。
3. 计算指标时展示公式、原始值、单位和期间，不混用不同币种或会计口径。
4. 区分历史事实、计算结果、压力情景和假设；进行敏感性分析时说明假设。
5. 不自动批准、拒绝或调整授信额度，不将模型分数当作最终信用决策。
6. 对缺失资料、异常波动和潜在偏差列出人工核查事项，最终决策由授权人员作出。
